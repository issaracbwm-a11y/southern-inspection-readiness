# คู่มือใช้งาน — ระบบสำรวจความพร้อมการบูรณาการตรวจสอบเครื่องชั่งตวงวัดสินค้าเกษตร ภาคใต้ 2570

## ผู้ใช้ 3 บทบาท

| บทบาท | ทำอะไรได้ |
|---|---|
| **เจ้าหน้าที่หน่วยงาน** | กรอก/แก้ไขความพร้อมของหน่วยงานตนเองเท่านั้น ดูแดชบอร์ดและรายงานได้ |
| **ผู้ดูแลระบบ** | ทุกอย่าง + กรอกแทนหน่วยงานใดก็ได้ ยืนยันประเด็นแผน แก้ไขแผน บันทึกข้อสรุปที่ประชุม กำหนดสิทธิ์ผู้ใช้ |
| **ผู้บริหาร** | ดูแดชบอร์ด รายวัน โหมดประชุม และรายงาน (แก้ไขไม่ได้) |

ใช้ได้ทั้งคอมพิวเตอร์และ iPhone (บน iPhone เมนูอยู่แถบล่าง; กด แชร์ → "เพิ่มไปยังหน้าจอโฮม" เพื่อเปิดเหมือนแอป)

## สำหรับเจ้าหน้าที่หน่วยงาน: กรอกความพร้อม

1. เข้าสู่ระบบ → เมนู **กรอกความพร้อม**
2. เลือก **รอบการตรวจ** (การ์ดด้านบนแสดงสถานะของแต่ละรอบ)
3. ตาราง **สรุปตามแผน** แสดงจำนวนที่หน่วยงานได้รับมอบหมายต่อวันโดยอัตโนมัติ
4. ส่วน **ความพร้อมรายวัน** — กรอกจำนวนที่พร้อมจริงของแต่ละวัน
   - กด **กรอกเท่าแผนทุกวัน** ถ้าพร้อมครบ แล้วค่อยแก้เฉพาะวันที่ไม่ครบ
   - วันไหนไม่ไปเลย ให้เอาเครื่องหมายออกที่ **พร้อมเข้าร่วมวันนี้**
   - รถเครน/รถกระบะตามแผนหมายถึง **พร้อมพนักงานขับรถ**
   - ช่องว่าง = ยังไม่กรอก (ระบบไม่ถือว่าเป็น 0)
5. ถ้าเข้าร่วมรอบนี้ไม่ได้เลย ติ๊ก **ไม่สามารถเข้าร่วมปฏิบัติงานในรอบนี้ได้** และระบุเหตุผล
6. กรอก **ชื่อผู้ประสานงาน** (บังคับ) เบอร์โทร ปัญหาและข้อจำกัด หมายเหตุ
7. หากต้องการทรัพยากรเพิ่ม ติ๊ก **ต้องการขอรับการสนับสนุน** แล้วระบุจำนวน
8. ระบบแสดง **สถานะหากส่งตอนนี้** ให้เห็นก่อนส่ง
9. กด
   - **บันทึกฉบับร่าง** — เก็บไว้ทำต่อ (แดชบอร์ดยังแสดง "ยังไม่ตอบ")
   - **ส่งยืนยัน** — ยืนยันความพร้อม แดชบอร์ดอัปเดตทันที
10. ส่งแล้วต้องการแก้ → กด **แก้ไขข้อมูล** แก้แล้ว **ส่งยืนยัน** อีกครั้ง
    (ถ้ากดบันทึกฉบับร่างระหว่างแก้ สถานะจะกลับเป็น "ยังไม่ตอบ" จนกว่าจะส่งใหม่)
11. **ดูประวัติการส่ง** แสดงทุกครั้งที่บันทึก/ส่ง พร้อมเวลาและผู้ส่ง

## ความหมายของสี

- 🟢 **พร้อม** — ครบตามแผนทุกวันทุกรายการ
- 🟡 **พร้อมบางส่วน** — ขาดบางรายการหรือบางวัน หรือมีข้อจำกัดสำคัญค้าง
- 🔴 **ไม่พร้อม** — เข้าร่วมไม่ได้ หรือไม่มีเจ้าหน้าที่พร้อมเลย
- ⚪ **ยังไม่ตอบ** — ยังไม่ส่งยืนยัน (ฉบับร่างนับเป็นยังไม่ตอบ)
- 🟣 **แผนรอยืนยัน** — หน่วยงานพร้อมครบ แต่แผนของรอบนั้นยังมีข้อขัดแย้ง (เช่น รถกระบะรอบ 4) จึงยังไม่แสดงเขียว

## การอ่านแดชบอร์ด

- **แถวตัวเลขด้านบน**: นับเป็น "หน่วยงาน × รอบ" รวม 16 ช่อง
- **การ์ดรอบ**: "พร้อม / แผน" = จำนวนที่พร้อมได้ **ทุกวัน** ของรอบ (วันที่น้อยที่สุด) เช่น เครน 1/2 ขาด 1 · ร้อยละคิดจากผลรวมรายวัน
- **Readiness Matrix**: คลิกช่องใดก็ได้เพื่อดูรายละเอียดรายวันของหน่วยงานนั้น
- **กราฟ**: ร้อยละความพร้อมรายรอบแยกตามทรัพยากร

## เมนูรายวัน

ตาราง 20 วัน แยกหน่วยงาน กรองได้ตามรอบ วัน จังหวัด หน่วยงาน สถานะ — เลือก **รวมทุกหน่วยงาน** เพื่อดูยอดรวมต่อวัน

## โหมดประชุม (สำหรับจอใหญ่)

1. เมนู **ประชุม** → เลือกรอบ → กด **เต็มจอ**
2. หน้าจอแสดง ตารางความพร้อม 4 หน่วยงาน, ทรัพยากรตามแผนกับที่ยืนยัน, ทรัพยากรที่ขาด, หน่วยงานที่ยังไม่ตอบ, ปัญหาที่ต้องตัดสินใจ
3. ผู้ดูแลระบบบันทึก **ข้อสรุปที่ประชุม** การจัดสรรเพิ่มเติม ผู้รับผิดชอบ กำหนดดำเนินการ (เก็บแยกจากข้อมูลที่หน่วยงานส่ง)

## รายงาน

6 รายงาน: รายรอบ, รายหน่วยงาน, รายวัน, ทรัพยากรที่ขาด, หน่วยงานที่ยังไม่ตอบ, ประกอบการประชุม

- **ส่งออก Excel** — ได้ไฟล์ .xlsx รวมทุกรายงาน แยกแผ่นงาน มีสีตามสถานะ
- **พิมพ์ / บันทึก PDF** — เลือกรายงานแล้วกด ปลายทางเลือก "บันทึกเป็น PDF" (A4 แนวนอน) บน iPhone: แชร์ → พิมพ์ → แชร์ไฟล์ PDF

## สำหรับผู้ดูแลระบบ: จัดการแผน

- **รายการรอยืนยัน**: เมื่อได้ข้อยุติ (เช่น ที่ประชุมยืนยันรถกระบะรอบ 4) ให้พิมพ์ผลการยืนยันแล้วกด **ยืนยันแล้ว** สถานะ "แผนรอยืนยัน" จะเปลี่ยนเป็นสีตามข้อมูลจริง
  - การยืนยันไม่เปลี่ยนตัวเลขแผนให้อัตโนมัติ ถ้าตัวเลขต้องเปลี่ยน ให้แก้ในตาราง **แก้ไขแผน** ด้วย
- **แก้ไขแผน**: แก้จำนวนต่อวันรายหน่วยงานและค่าหัวตาราง ระบบถามยืนยันก่อนบันทึก
- **ผู้ใช้งาน** (เมื่อเชื่อม Supabase): กำหนดชื่อ บทบาท และหน่วยงานของแต่ละบัญชี

## โหมดสาธิต

ถ้ายังไม่เชื่อม Supabase จะมีแถบสีเหลือง "โหมดสาธิต" ด้านบนตลอดเวลา

- เลือกผู้ใช้ทดลองได้โดยไม่ต้องใช้รหัสผ่าน
- ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น **ไม่ใช่ข้อมูลกลาง** หน่วยงานอื่นจะไม่เห็น
- กด "โหลดข้อมูลทดสอบ" (หน้าเข้าสู่ระบบ หรือ จัดการแผน) เพื่อดูตัวอย่างทุกสถานะ
